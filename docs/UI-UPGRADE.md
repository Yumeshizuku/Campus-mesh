# 0.2 界面更新

0.2 版本增加了外观设置和一些日常聊天中常用的操作，让切换会话、保存草稿和给多位好友发消息更方便。下面记录的是这个版本的变化；Rust 通信协议、密钥和消息传输逻辑没有调整。

## 新增了哪些功能

- 应用分为聊天、附近、身份和自定义四个页面。连接设备、公钥管理等操作也有了集中入口。
- 私聊和群发各自显示在独立会话中，消息用左右气泡区分，并显示中文发送状态。搜索只查找当前会话，最多展示最近 200 条匹配消息。
- 每个会话都会在本机保存草稿，切换页面或重新启动应用后可以接着写。
- 外观可以跟随系统，也可以固定为浅色或深色。另有四种主题色、14/16/18/20 四档聊天字号，以及紧凑气泡和时间显示开关。
- 可以保存最多 8 条快捷短语，每条最多 80 个字符。点选短语后，它会先填入输入框，确认后再发送。
- 常用好友和会话可以置顶，常用的群发成员组合也可以保存在本机。群发时仍然为每位收件人分别加密消息；这个版本没有加入群管理员或自动同步成员名单的功能。
- 群发时如果只有部分消息提交失败，应用会记住尚未提交的收件人。在文字没有修改的情况下再次发送，只会重试这些成员。修改成员后，旧的重试列表会清除；消息是否真正送达，仍由端到端 ACK 确认。
- “恢复默认外观”只重置主题、颜色、字号、显示密度和时间设置，身份、聊天记录、草稿、快捷短语及常用群发都会保留。
- 长按消息可以复制内容。界面中的设备连接和消息送达状态都来自实际通信结果。

## Android 和 iOS 怎么使用

Android 可以通过顶部的会话选择器切换好友或常用群发，在会话右侧的“⋯”菜单中设置常用好友、编辑群发成员。输入区独立于消息列表，搜索消息或刷新列表时不会重新创建输入框。“附近”页面支持扫码、粘贴公钥、启停蓝牙、连接已授权的局域网，以及调用 Android 系统的 Wi-Fi Direct 配对功能。主题和字号保存在私有 SharedPreferences 的 `appearance` 配置中，升级后会保留原来的 `mesh` 身份配置。

iOS 的聊天首页是一张可以搜索的会话列表，向右轻扫可将会话设为常用。进入会话后可以搜索消息、保存草稿，也可以从会话菜单编辑群发成员。输入区会随系统键盘调整位置；阅读旧消息时收到新消息，界面会提供“最新消息”按钮，方便自己决定何时跳到列表底部。主题和偏好通过 UserDefaults 保存，再由环境对象同步到各个页面；聊天字号会随系统动态字体设置缩放。

两个平台都使用适应明暗模式的语义背景色。Android 的间距和字号分别使用 dp、sp，主要按钮的触控高度至少为 48 dp；iOS 发送按钮的触控区域至少为 44 pt。在 0.2 版本的验证阶段，iOS 还需要通过 Xcode 完整编译，并在设备上检查动态字体和 VoiceOver。后续构建进展见 [验证报告](VERIFICATION.md)。

## 需要检查的操作

1. 添加两位好友，分别输入不同草稿。切换会话和底部页面，检查草稿与消息是否仍属于对应的好友。
2. 重启应用，检查身份和公钥是否保持不变，外观、字号、快捷短语及草稿是否保留。
3. 搜索当前会话中的关键词，检查结果是否只来自这个会话，退出搜索后草稿是否保持原样。
4. 阅读旧消息时接收新消息，检查列表是否保持当前位置；发送成功后输入框应清空，发送失败时应保留文字。
5. 保存一个包含两位成员的群发组合，让其中一位收件人的消息提交失败。再次发送时应只重试未提交的成员，并清楚区分“已排队”和“已送达”。
6. 选择深色、最大字号和紧凑模式，检查键盘弹出、长中文、多行消息、横屏和系统大字体下的显示效果。
7. 恢复默认外观，检查公钥、聊天记录和草稿是否完整保留。

构建、Lint 和模拟器检查的结果见 [界面验证记录](UI-VERIFICATION.md)。通信部分的测试情况见 [验证报告](VERIFICATION.md)；界面检查通过，并不代表 BLE 或 Wi-Fi Direct 已经通过真机测试。
