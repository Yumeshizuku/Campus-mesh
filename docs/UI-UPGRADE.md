# 0.2 界面升级

本轮聚焦自定义与日常操作，Rust 通信协议、密钥和传输逻辑保持不变。

## 两端共同的交互

- 四个入口：聊天、附近、身份、自定义。连接方式与公钥操作集中展示。
- 会话独立展示私聊与群发，使用左右气泡、中文交付状态；搜索当前会话，最多展示匹配的最近 200 条。
- 会话草稿本机保存，切换页面或重新启动后恢复。
- 三种外观：跟随系统、浅色、深色；四种主题色；14/16/18/20 聊天字号；紧凑气泡和时间显示开关。
- 快捷短语最多 8 条、每条最多 80 字符。点击只填入输入框，由用户确认发送。
- 常用好友/会话置顶，以及本机保存的常用群发成员组合。群发仍按每位成员分别加密，不新增群管理员或自动名册协议。
- 群发提交部分失败时，保存剩余收件人；文本未修改的再次发送只重试未完成的成员。编辑成员后清除旧的重试列表；这不改变核心的端到端 ACK 语义。
- 恢复默认外观只重置主题、颜色、字号、密度与时间；不删除身份、聊天、草稿、快捷短语或常用群发。
- 消息复制需要用户主动长按操作；界面不显示伪造的已连接设备或送达状态。

## 平台操作

Android：点击顶部会话选择器切换好友/常用群发；会话右侧“⋯”菜单设置常用好友或编辑群发。底部输入区独立于消息列表，搜索与轮询不会重建输入框。附近页可扫码、粘贴公钥、启停蓝牙、连接已授权局域网及使用 Android 系统 Wi-Fi Direct 配对。主题和字号保存在 `appearance` 私有 SharedPreferences；升级保留原 `mesh` 身份配置。

iOS：聊天首页是可搜索的会话列表，向右轻扫设置常用，点入会话可搜索消息及保存草稿。会话菜单可编辑群发成员。输入区随系统键盘避让，收到新消息时提供“最新消息”跳转，避免强制把正在阅读的旧消息拉到底部。主题与偏好使用 UserDefaults，设置通过环境对象同步到各页；聊天字号随系统动态字体比例缩放。

颜色使用语义背景和明暗适配；Android 使用 dp 间距、sp 字号，主要按钮触控高度至少 48dp，iOS 发送触控区至少 44pt。iOS 原生界面仍需在 Xcode/真机检查完整类型编译、动态字体与 VoiceOver。

## 回归检查

1. 添加两位好友，各输入不同草稿，切换会话和底部页面，确认草稿与消息不串人。
2. 重启应用，确认原身份/公钥不变，外观、字号、快捷短语及草稿保留。
3. 搜索当前会话关键词，确认只显示当前会话，退出搜索不修改草稿。
4. 不在列表底部时收到新消息，确认不强制跳转；发送成功后输入框清空，失败时保留。
5. 保存两个成员的群发；造成一个收件人提交失败，再次发送应仅重试未提交成员。已排队与已送达仍分别显示。
6. 选择深色、最大字号和紧凑模式，检查键盘弹出、长中文、多行消息、横屏与高字体缩放。
7. 恢复默认外观，确认公钥、记录和草稿都保留。

构建、Lint 与模拟器检查结果另见 `UI-VERIFICATION.md`。历史核心报告 `VERIFICATION.md` 保留上轮无线验收限制，不将本轮界面检查当成 BLE 或 Wi-Fi Direct 真机验收。
