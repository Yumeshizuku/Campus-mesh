## 三跳的证据要求

普通同一热点中四台手机通常彼此都能直连，不能直接作为无线三跳证据。必须验证每条邻接边，以及每条不应存在的旁路确实不可达。Linux 四进程脚本只配置 A–B、B–C、C–D 并验证断线；这是真实 TCP 协议三跳，但不等于无线射频三跳。

## 学校和 Windows

白板无法装软件，不测试安装、远程执行或绕过限制。Windows 中继仅在自己的测试电脑或获得明确许可后验证。校园 Wi-Fi 如隔离客户端，停止该连接尝试，使用合法热点/BLE 或由管理员调整授权网络。可选 Windows 用例应记录许可来源、机器归属、端口范围和撤销方式。
