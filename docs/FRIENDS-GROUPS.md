# 扫码好友、设备记忆与 Mesh 群聊

alpha-0.5.0 将好友和群聊统一交给通信核心保存，两端继续使用现有的 Telegram 风格界面，iOS 的 Liquid Glass 控件也会保留。

## 好友与设备

在“身份”页设置自己的昵称，并让好友扫描二维码。私聊需要双方互扫；“附近”也可以粘贴二维码文本。新二维码带有设备 ID、公钥、昵称和签名，旧版公钥二维码仍可导入，中文昵称、群名和表情可完整分享。请当面核对设备 ID；二维码自带签名可以校验内容是否被改动，但不能代替对二维码来源的确认。

设备 ID 是签名公钥的 SHA-256 指纹，首次创建身份时生成，并随私钥一起保存在应用本地。升级、重启或修改昵称都会保留这个 ID，不使用手机号、MAC 地址或可变化的蓝牙地址。好友公钥、备注和手动添加的局域网地址也会保存，重新打开应用后不必重复添加。卸载、清除数据或丢失身份文件后会产生新身份。

在好友会话菜单中查看设备信息、设置备注。备注只影响自己看到的名称，留空后显示对方昵称。收到好友的新消息后，会更新其昵称，并保留自己设置的备注。群成员之间可以聊天，但加入同一个群不会自动建立私聊好友关系。

## 群聊

从聊天页创建群聊，可以先选择已有好友，也可以先创建只有自己的群，再邀请其他人。每个群都有固定 ID，允许重名，最多 32 位成员（包含群主）；一台设备最多保存 64 个群。群主可以改群名、添加或移除成员，以及解散群聊；普通成员可以查看成员和退群。退出和解散都会保留本机聊天记录。

群主生成的入群二维码有效 10 分钟，只能使用一次。重新生成会撤销同一群的上一个邀请。扫码后，入群请求通过 Mesh 发送给群主；在有效期内送达后，群主签发并分发新的成员名单。界面会显示等待同步的申请；申请过期后需要重新扫码。如果群已满，请群主先调整成员，再生成邀请。

群成员名单由群主签名，并带有递增版本号。其他成员不能冒充群主管理群聊，旧的成员信息也不能覆盖新的版本。群消息携带群 ID、成员版本和统一消息 ID，每位接收者分别获得加密封装。发送方只显示一条消息，并汇总各成员的端到端送达回执，例如“已送达 1/2”；缓存不足时不会只提交其中一部分。

群名、成员变更、退群和解散也需要通过 Mesh 送达。离线期间无法立即通知所有设备，已经送达的消息不会被远程删除。若离线太久、错过了已过期的成员更新，仍在群内的成员可以在群信息页点击“同步群信息”，向群主请求最新名单。被移除后重新加入需要新的邀请。新成员不会自动获得旧聊天记录，本版不含群主转让、多人管理员、附件或云端历史同步。

## Mesh 详细参数

在“附近 → 详细传输参数”调整，保存后写入本机状态文件。恢复默认值会先填入默认参数，再由用户保存。

| 参数 | 默认值 | 范围与作用 |
|---|---:|---|
| 最大跳数 | 8 | 1–8；用于新封装，1 表示只能直达 |
| 消息有效期 | 86400 秒 | 60–86400 秒；新消息、回执和群信息使用此有效期，入群请求还受邀请到期时间限制 |
| 同步间隔 | 5 秒 | 1–60 秒；TCP 与 BLE 空闲时的目标周期，慢连接会拉长实际周期 |
| TCP 每批封装数 | 24 | 1–24；TCP inventory 同步每批发送上限，BLE 每轮仍只发送一个封装 |
| TCP 邻居上限 | 300 | 1–300；不能低于已记住的手动邻居数量；BLE 保留每侧最多 4 条连接的限制 |
| 待传封装上限 | 4096 | 64–4096；包括本人消息、回执、群信息和中继密文，不能低于当前占用 |

中继开关保留在“身份”页。关闭中继后仍收发自己的消息。传输采用机会式 Mesh 多跳与存储携带转发，BLE、TCP 可以并行；没有端到端路径时会等待下一次接触。跳数更高、间隔更短通常会增加耗电，群聊也会按接收人数增加密文封装数量。

## 升级与旧功能替换

原“保存常用群发”、本机群发成员组合和逐成员提交重试入口已经由正式群聊取代。升级时，旧组合会创建一次固定 ID 群聊，并将相关本机记录与草稿映射到新 ID；迁移成功后才清除旧组合。若成员资料不全、缓存不足或保存失败，旧数据会保留供之后重试。迁移不会自动重发旧消息，未完成的旧群发原文只会留作草稿。

覆盖安装需要兼容的应用签名。Android 的不同 CI 调试包可能不能直接覆盖，卸载会丢失本机数据，更新前请先阅读[Android 交付说明](ANDROID-DELIVERY.md)。

仅存在于历史消息、没有保存成员组合的旧群发会话仍可查看记录，需要另建群聊才能继续发送。旧客户端可以继续中继新封装，但参加新群聊需要升级到 alpha-0.5.0。

核心协议和持久化由自动测试覆盖；原生编译、模拟器操作及 IPA 打包结果记录在[验证报告](VERIFICATION.md)。跨手机蓝牙、无线多跳和熄屏耗电仍需真机验收。
