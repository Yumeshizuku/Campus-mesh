# 0.3 Telegram 风格界面

将常用聊天流程改成会话列表与独立聊天页，保留 Campus Mesh 名称、公钥身份、原有通信核心与自定义设置。

## 界面

- 新安装默认蓝色强调色；Android 蓝色工具栏与抽屉导航入口，iOS 简洁原生导航栏。已有的主题色、字号和深浅色偏好继续保留。
- 会话列表使用圆形首字头像、最近消息、时间、本机未读数、草稿提示与常用会话排序。没有联系人时展示真实空状态。
- Android 支持“全部 / 私聊 / 群发”筛选及右下角新建会话按钮；点击会话进入聊天页，返回按钮回到列表。
- 聊天页收起底部页签，显示圆形头像与名称；顶部菜单提供会话搜索和设置。
- 默认蓝色主题下，浅色模式使用白色接收气泡、浅绿发送气泡和淡灰绿背景；深色模式使用深蓝背景与气泡。已选择其他主题色时保留该主题色的浅色气泡。
- 使用带方向的圆角气泡、日期分隔、紧凑时间/状态信息与圆形纸飞机发送按钮。快捷短语收进输入区菜单。
- 自定义外观、草稿保存、常用群发和部分提交失败重试功能继续保留。头像颜色由身份/会话 key 稳定生成，没有伪造用户照片。

## 状态语义

未读数字是本机界面查看记录，保存在本机偏好中，不会发出新的远程“已读”回执。进入会话后将该会话已有消息标为本机已查看。

“✓ 已送达”仍由原通信核心验证端到端 ACK 后显示；等待送达和已过期沿用真实核心状态。没有新增虚假的在线时间、通话、文件附件或云同步按钮。
